# OpenClaim

사용자가 자신의 개인정보 유출 보상 신청을 준비하는 로컬 우선 오픈소스 도구입니다.

개발 방향: Rust 공통 핵심, 브라우저 WebAssembly, 로컬 MCP 서버, 보조 Agent Skill.
실제 개인정보는 GitHub, 프로젝트 운영자, 클라우드 AI로 보내지 않습니다.
신청 제출과 본인인증은 사용자가 자신의 환경에서 직접 수행합니다.

현재 개발 중입니다. `main`은 안정 버전용이며 초기 구현은 `dev/initial-build`에서 진행합니다.
정식 릴리스 검증 후 병합하고 병합된 임시 브랜치를 삭제합니다.
