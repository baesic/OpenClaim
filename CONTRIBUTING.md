# Contributing

Use feature branches and pull requests. Keep changes scoped to user-operated self-claim preparation. Use synthetic data only; do not report real claims or upload evidence in issues. See [AGENTS.md](AGENTS.md) and [SECURITY.md](SECURITY.md) for data boundaries.

Run the checks listed in README. A change to MCP/WebMCP must preserve the public-only input/output boundary and rejection of extra fields. Browser changes must retain manual operation when WebMCP is unavailable. Submit no private material to CI or cloud tools.

Contributions are under Apache-2.0. Do not claim an official relationship with any business or government agency.
