WebMCP 미연결

WebMCP는 지원 브라우저의 공개 도구 연결 기능이며 원격 MCP 서버 주소가 아닙니다. 지원하지 않아도 아래에서 직접 도구를 선택할 수 있습니다.

OPENCLAIM_RESPONSE_PLAN

상황별 대응안과 신청 경로

공개 안내

공개 대응안의 종류를 선택하세요. 개인 피해를 신고·입력하는 기능이 아닙니다. openclaim_guidance_index의 목록과 openclaim_response_plan의 결과를 사용합니다.

OPENCLAIM_TEMPLATE

Agent 도구 계약

지원 환경에서 네 개의 공개 도구를 등록합니다. 빈 객체 또는 공개 식별자만 받으며, 개인 작성 공간은 읽지 않습니다.

실제 MCP 도구 스키마
openclaim_choices({})
openclaim_guidance_index({})
openclaim_response_plan({"scenario":"notice_only"})
openclaim_template({"kind":"compensation"})

공식 경로와 최신 요건

조회·인증·신청·제출은 본인이 직접 수행합니다. 접수 조건·비용·보상 여부는 공식 기관에서 확인하세요. OpenClaim은 결과를 보장하지 않습니다.
