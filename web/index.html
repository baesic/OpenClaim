BROWSER RUNTIME PACKAGE

공개 도구와 개인 작성을 분리

공개 WASM 실행 화면에서 대응안과 양식을 확인하고 WebMCP를 연결합니다. 개인정보 입력 항목은 없습니다.

문서 작성이 필요하면 별도 선택형 로컬 작성 도구를 사용합니다. 이 화면에는 WebMCP를 등록하지 않으며, 초안·증빙 해시·암호화 보관 파일을 내 기기에서 처리합니다.

브라우저 실행 패키지 ↓

다운로드한 파일은 신뢰하는 로컬 정적 서버에서 실행하세요. WASM 실행에는 HTTP/HTTPS가 필요합니다. WebMCP는 지원 브라우저에서만 연결되며 일반 원격 MCP URL을 대신하지 않습니다.

배포는 GitHub에서, 운영은 사용자에게

GitHub Actions는 공개 소프트웨어를 빌드·검증·배포합니다. 서비스 페이지는 설치 파일과 사용 안내를 제공하며 신청인 정보를 받지 않습니다. 사용자 PC와 브라우저가 실행을 담당하고, OpenClaim 운영자는 신청·사건 처리에 관여하지 않습니다.

프로젝트는 개인 사건을 전송하는 기능을 제공하지 않습니다. AI 호스트·확장·화면 공유 권한까지 통제할 수는 없으므로 민감정보는 신뢰하는 로컬 환경에서 처리하세요. 개발은 dev/initial-build에서 유지하며, 정식 제공 결정 후 main 전환과 임시 브랜치 정리를 진행합니다.
